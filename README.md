# caduz7

Site simples que funciona através de uma planilha Excel.

## Como usar

1. Abra o arquivo `index.html` no navegador **ou** rode um servidor local.
2. Clique em **Escolher planilha** e selecione um arquivo `.xlsx` ou `.xls`.
3. Selecione a aba desejada.
4. Use a busca para filtrar os dados.

## Executar com servidor local

```bash
python3 -m http.server 8000
```

Depois, acesse `http://localhost:8000`.
